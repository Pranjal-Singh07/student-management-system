# Student Management System

A Python-based Student Management System for managing student information and academic records.

## Features

- Student profile management
- Student information storage
- Attendance management
- Marks management
- Fees management

## Technologies Used

- Python
- SQLite

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Pranjal-Singh07/student-management-system.git
```

2. Open the project folder:

```bash
cd student-management-system
```

3. Run the program:

```bash
python "STUDENT PROJECT version2.0.py"
```
